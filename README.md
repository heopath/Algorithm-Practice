## 왜 30분 룰인가

초보 단계에서 한 문제를 3시간 붙잡는 것은 공부가 아니라 시간 낭비다.
모르는 유형은 오래 고민한다고 떠오르지 않는다.
해설을 보고 "이렇게 푸는 거구나"를 쌓는 편이 이 시기에는 훨씬 빠르다.

대신 **본 것은 반드시 갚는다.** 그날 안에 다시 구현하고, 3일 뒤 한 번 더 푼다.
이 두 가지를 안 하면 30분 룰은 그냥 "답 보고 넘어가기"가 된다.

## 4주 구성

문제 목록과 링크는 [PLAN.md](PLAN.md)에 있다.

| 주차 | 주제 | 문제 |
|---|---|---|
| 1주차 | 손 풀기 — Lv.1 위주 | 7 |
| 2주차 | 자료구조 — 해시·스택/큐·정렬·힙 | 11 |
| 3주차 | **BFS/DFS + 완전탐색** | 9 |
| 4주차 | 그리디·DP·이분탐색 | 8 |

**3주차가 가장 중요하다.** BFS/DFS는 코테 출제 빈도 1위이고 여기서 막히면 대부분 떨어진다.
1~2주차는 사실상 3주차에 도달하기 위한 준비 과정이다.

### 하지 않는 것

시간을 아끼기 위해 명확히 제외한다. 일반적인 코테 범위를 벗어난다.

- 세그먼트 트리 / 펜윅 트리
- 네트워크 플로우
- 최소 스패닝 트리(MST)
- 위상 정렬
- Lv.4 이상 문제

"코테 필수 알고리즘 30선" 같은 목록에는 이런 것이 다 들어 있지만,
그것은 상위권 공채나 경력직 기준이다.
